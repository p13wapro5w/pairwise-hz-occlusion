# pairwise-hz-occlusion

穿过城门时远处整片城墙突然消失，回头看又全部出现，贴着墙走时柱子和角色一起被剔掉：HZB 只生成一张最大 mip，遮挡查询用保守包围盒却按最小深度投影；反向 Z 的深度比较方向写反，近处物体被当成遮挡物；相机 cut 后没有重建层级，旧金字塔把新视角整片剔掉；两阶段遮挡先剔小物体再剔大物体，大城墙在第一阶段被小柱子挡掉；蒙皮角色用绑定姿势包围盒，动作后包围盒与网格错位，角色被自身影子剔除；实例化物体共用原型包围盒，旋转缩放后包围盒偏小；透明物体写进深度金字塔，玻璃后面的场景被误剔；多相机分屏共用一张 HZB，左右屏深度范围不同导致误判；浮点深度精度不足，远处城墙的 mip 深度被量化成同一值；遮挡查询异步回读晚两帧，快速转身时用旧结果剔除新视角；超大物体跨多个 mip，采样时只取一个 texel；地形 LOD 切换后包围盒没更新，低模被高模的旧包围盒挡住。render/hz_occlusion.py 是核心，tests/test_hz_occlusion.py 15个红。要修的是：完整 mip 链；反向 Z 比较；cut 重建；两阶段顺序；蒙皮包围盒；实例包围盒；透明隔离；多相机隔离；深度精度；异步时效；跨 mip 采样；LOD 包围盒。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
